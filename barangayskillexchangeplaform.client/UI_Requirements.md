# Barangay Skill Exchange — LinkedIn-Inspired UI Prompt for Figma Make

Create a modern, highly polished LinkedIn-inspired web application UI for a platform called **“Barangay Skill Exchange”**. The platform is a community-driven social network where residents can offer skills, connect with neighbors, request services, and exchange help within the barangay.

---

# DESIGN STYLE

- Strong LinkedIn-inspired visual identity
- Clean, modern, professional, community-centric
- Soft blue + white + subtle gray palette
- Rounded cards, modern shadows, smooth spacing
- Responsive desktop-first design
- Minimalist but information-rich
- Use glassmorphism subtly for overlays/modals
- Highly polished SaaS/social platform aesthetic
- Mix of LinkedIn + Facebook Groups + Upwork marketplace

---
